# Contributing to Flatworm

Please read the below content if you plan on opening pull requests, sending patches to my email or socials, or opening issues

---

### How to Write Issue's
there are currently no guidelines on how to structure an Issue. that does not mean you are not allowed to create one

### pull requests (through github)
1. fork the repo
2. push your local commits
3. pull request with a summary of your changes

### pull requests (through discord)
1. **Commit changes locally**
   ```bash
   git commit -m "patch doing patch things"
   ```
2. **Generate Formatted Patch**
    ```bash
    git format-patch -1 HEAD
    ```
3. Send me the outputted patch file over discord (my username is **jerrald56**)
